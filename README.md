# PIXEL PETS — Jogo da Memória

Jogo da memória com animais em pixel art retrô, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Como executar
1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador.
3. Não é necessário instalar dependências.

## Níveis
- Fácil: 4 pares (8 cartas).
- Médio: 6 pares (12 cartas).
- Difícil: 10 pares (20 cartas).

## Funcionalidades
- Embaralhamento automático das cartas.
- Animação para virar as cartas.
- Verificação dos pares.
- Cronômetro, contador de jogadas e pares encontrados.
- Recorde local por dificuldade (localStorage).
- Efeitos sonoros com opção de ligar/desligar.
- Tela de vitória e opção de jogar novamente.
- Layout adaptável a computador e celular.
- Ilustrações SVG em pixel art na pasta `assets`.

## Tecnologias
HTML5, CSS3, JavaScript, SVG e Web Audio API.

## Estrutura
- `index.html`: estrutura da página.
- `style.css`: aparência, animações e responsividade.
- `script.js`: regras e lógica do jogo.
- `assets/`: ilustrações dos animais.
